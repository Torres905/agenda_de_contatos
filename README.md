# Agenda de Contatos — Python

Sistema simples de gerenciamento de contatos desenvolvido em Python.

## Funcionalidades
- ✅ Adicionar contato (nome, telefone, e-mail)
- ✅ Listar todos os contatos cadastrados
- ✅ Buscar contato por nome
- ✅ Editar dados de contatos existentes
- ✅ Excluir contato
- ✅ Interface de menu no terminal

## Conceitos aplicados
- Listas para armazenamento de dados
- Dicionários para organização das informações
- Estruturas de repetição e decisão
- Validação de números e entradas
